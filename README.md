# 🍲 국밥 타이쿤 · Business Simulator

새벽시장에서 재료를 사고, 국밥을 끓여 팔고, 카페와 VIP 라운지까지 키우는 **3D 식당 경영 게임**입니다.
브라우저만 있으면 바로 할 수 있어요. 설치도, 서버도 필요 없습니다.

▶ **바로 하기**: https://korean568.github.io/Business-Simulator/

![국밥 타이쿤](logo.png)

## 어떤 게임인가요

기초자금 30만원으로 시작해서 **1000만원**을 모으면 이깁니다.
하루는 이렇게 흘러가요.

1. 🌅 **새벽시장** — 가판대를 돌며 고기·콩나물·뼈·양념을 사요
2. 🔪 **재료 준비** — 고기를 썰고, 콩나물을 다듬고, 뼈를 씻어 육수를 끓여요
3. ☀️ **점심 영업** — 돼지국밥·콩나물국밥·뼈해장국을 끓이고 토핑을 올려 서빙해요
4. ☕ **오후 카페** — 음료를 만들어 팔고, 재료를 섞어 **나만의 메뉴**도 만들어요
5. 🌙 **저녁** — 업그레이드 상점에서 가마솥·칼·간판을 올리고, 직원을 고용해요

가게가 커지면 **2층 카페**와 **3층 VIP 라운지**가 열리고, 세 층에서 동시에 영업합니다.
직원을 고용하면 대신 서빙해주고, 부사장을 뽑으면 장보기까지 맡길 수 있어요.

## 더 있는 것들

- 😡 **진상 손님** — 방망이·태이저건·경찰 신고로 내보내요. 경비원을 고용하면 멱살을 잡고 끌어내요
- 🏙️ **시내와 대도시** — 은행, 방송국, 대형마트, 고급 와인샵, 호신용품점, 초고급 자동차 가게
- 🚌 **이동수단** — 버스는 15초, 비싼 차일수록 빨라요 (직접 운전도 해요)
- 🕯️ **공포의 집** — 시장 바닥의 문양을 밟으면 1인칭 3D 공포게임이 시작돼요. 5단계까지 있고, 괴물에게 잡히면 **이상한 곳**으로 끌려가요
- 😵 **피곤함** — 퇴근이 늦을수록 화면이 어두워지고, 100%가 되면 쓰러져요

## 조작

| 곳 | 조작 |
| --- | --- |
| 새벽시장 | 방향키·WASD 이동 · `1`~`3` 구매 · `E` 나가기 |
| 재료 준비 | `1`~`8` 손질 · `Enter` 영업 시작 |
| 점심 영업 | `Q` `W` `E` 국밥 · `A` `S` `D` `F` 가마솥 · `1`~`4` 토핑 · `Z` `X` `C` `V` 서빙 · `Tab` 조립대 · `Backspace` 버리기 |
| 진상 손님 | `B` 방망이 · `G` 태이저건 · `H` 전화 |
| 층 이동 | `Shift`+`1`~`3` 층 · `Shift`+`4` 시내 · `Shift`+`6` 퇴근 |
| 공포의 집 | `WASD` 이동 · `Shift` 달리기 · `C` 웅크리기 · `F` 손전등 · `Q` 포기 |
| 공통 | `Esc` 일시정지 · 화면 위 `❓` 버튼으로 도움말 |

📱 휴대폰·태블릿에서는 왼쪽 **조이스틱**으로 움직이고, 화면을 끌어서 둘러봐요.

## 진행 저장

하루가 시작될 때마다 브라우저에 자동으로 저장돼요. 탭을 닫았다가 다시 열면 타이틀 화면에서 **이어하기**를 누르면 됩니다.

## 직접 돌려보기

`index.html` 파일 하나가 게임 전부입니다. 그냥 열어도 되고, 간단한 서버로 열어도 돼요.

```bash
python -m http.server 8000
```
